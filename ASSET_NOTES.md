# Asset and rendering notes

- `assets/id.png` is copied byte-for-byte from the newly supplied `/mnt/data/id(3).png`, which has a genuine alpha channel. It is embedded unchanged in the hero and ID dashboard SVGs. `assets/right_pointing.png` is copied byte-for-byte from the supplied pointing image and embedded unchanged in the connect SVG.
- Fonts embedded in every SVG: Inter Display Bold, Copyright 2016–2023 The Inter Project Authors, SIL Open Font License 1.1; and DejaVu Sans Mono, DejaVu fonts license. Text copies of both licenses are in `fonts/`.
- GitHub and Instagram brand paths are embedded from Simple Icons (CC0-1.0; https://github.com/simple-icons/simple-icons/tree/develop/icons). LinkedIn uses its conventional inline “in” monogram. All marks and text are inline; no external asset or icon request is made. The README contains the actual clickable links because links inside an SVG image are not clickable on GitHub.
- The newly supplied Instagram URL `https://www.instagram.com/the22yards.x/` is used for the THE 22YARDS.X cricket/editing page. The personal Instagram URL `https://www.instagram.com/rjvishwa_09/` is retained separately. The YouTube channel name was supplied without its direct URL, so it is shown as plain text and no URL has been guessed.
- All SVGs use inline PNG/font data URIs and local SVG definitions only. No runtime network requests or external assets are used by the SVGs. Animations are SVG SMIL; CSS `prefers-reduced-motion` rules disable CSS entrances and suppress SMIL motion. No JavaScript or `foreignObject` is used inside SVGs.
- The carousel uses a 12-second loop with three four-second slides; the ID card uses a six-second swing loop. Role labels cycle on an eight-second loop.
- No unverified GitHub contribution, follower, repository, or star counts are included. Repository overview text is based on user-provided descriptions. Neighborly's supplied URL returned 404 through the connected repository lookup, so it is retained as supplied but should be confirmed before publishing.
